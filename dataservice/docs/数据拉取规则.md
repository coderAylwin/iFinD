# iFinD 量化数据系统 — 数据拉取规则

## 1. 完整目录结构

```
IFIND_DATA/                                       # 项目根目录
├── raw/                                           # ← 原始K线数据（与 dataservice 同级）
│   ├── minute/                                    #   1分钟K线 (fetch_1m.py 产出)
│   │   ├── cn/2026/                               #     A股市场
│   │   │   └── 600000.SH.csv                      #     单只股票文件
│   │   ├── etf/2026/                              #     ETF市场
│   │   └── us/2026/                               #     美股市场
│   └── daily/                                     #   日线K线 (fetch_daily.py 产出)
│       ├── cn/2026/
│       ├── etf/2026/
│       └── us/2026/
│
└── dataservice/                                   # 数据服务代码
    ├── .env                                       # 配置文件
    ├── data/
    │   ├── lists/                                 # 清单文件（按市场区分）
    │   │   ├── hs300_list_cn.csv                  #     后缀 _cn → 存 cn/ 目录
    │   │   ├── etf_list_etf.csv                   #     后缀 _etf → 存 etf/ 目录
    │   │   ├── us_list_us.csv                     #     后缀 _us → 存 us/ 目录
    │   │   └── test_list.csv                      #     测试清单
    │   ├── usage.json                             #     分钟线本周用量（运行时生成）
    │   └── usage_daily.json                       #     日线本周用量（运行时生成）
    ├── docs/                                      # 文档
    ├── sdk/                                       # iFinD Python SDK
    └── scripts/
        ├── fetch_1m.py                            #   分钟线数据拉取
        └── fetch_daily.py                         #   日线数据拉取
```

**数据保存位置**：`IFIND_DATA/raw/` 目录下，与 `dataservice/` 同级。

## 2. 清单文件 → 市场目录映射

**关键规则：清单文件名最后一个 `_` 后的后缀决定市场目录。**

| 清单文件名 | 后缀 | 数据保存目录 |
|-----------|------|-------------|
| `hs300_list_cn.csv` | `cn` | `raw/{period}/cn/` |
| `etf_list_etf.csv` | `etf` | `raw/{period}/etf/` |
| `us_list_us.csv` | `us` | `raw/{period}/us/` |
| `zz500_list.csv`（无后缀） | — | `raw/{period}/cn/`（默认） |

> 其中 `{period}` 为 `minute` 或 `daily`，由脚本决定。

## 3. 分钟线与日线配置分离

`.env` 中两个独立配置项：

```env
# 分钟线清单（fetch_1m.py 使用）
STOCK_LISTS_1M=hs300_list_cn.csv

# 日线清单（fetch_daily.py 使用）
STOCK_LISTS_DAILY=hs300_list_cn.csv,etf_list_etf.csv,us_list_us.csv
```

**读取优先级**：
1. `STOCK_LISTS_1M` / `STOCK_LISTS_DAILY`（最优先）
2. `STOCK_LISTS`（通用回退值）
3. 脚本内置默认值 `hs300_list.csv`

分钟线可以只拉 A 股，日线可以同时拉 A 股 + ETF + 美股，互不影响。

## 4. 各脚本详情

### fetch_1m.py — 1分钟K线

| 项目 | 说明 |
|------|------|
| **接口** | `THS_HF()` |
| **数据保存路径** | `raw/minute/{market}/{year}/{code}.csv` |
| **指标** | `open;high;low;close;volume;amount` |
| **jsonparam** | `Fill:Original`（非交易时段不填充） |
| **时间粒度** | 按月分段，时间格式 `YYYY-MM-DD HH:MM:SS` |
| **断点续传** | 读 CSV 最后 `time` 列，+1 秒续拉 |
| **用量文件** | `data/usage.json` |

### fetch_daily.py — 日线K线

| 项目 | 说明 |
|------|------|
| **接口** | `THS_HD()` |
| **数据保存路径** | `raw/daily/{market}/{year}/{code}.csv` |
| **指标** | `open;high;low;close;volume;amount;preClose;turn` |
| **jsonparam** | 空字符串（无复权/填充参数） |
| **时间粒度** | 按月分段，时间格式 `YYYY-MM-DD` |
| **断点续传** | 读 CSV 最后 `date` 列，+1 天续拉 |
| **用量文件** | `data/usage_daily.json` |

## 5. 运行方式

```bash
cd IFIND_DATA

# 分钟线
python3 dataservice/scripts/fetch_1m.py

# 日线
python3 dataservice/scripts/fetch_daily.py
```

两个脚本各自独立跑，互不影响。

## 6. 补充说明

- **FILL 参数**（仅分钟线）：`Original`=不填充非交易时段（推荐），`Previous`=前值填充，`Blank`=空值填充
- **预算控制**：两个脚本各自有独立的本周用量计数，超限自动停止
- **幂等性**：断点续传机制保证重复跑不会重复也不会漏
