## 二、表命名规范与表结构

### 2.1 命名规范

```
ml_{market}_{symbol}_history_{timeframe}_{year}
```

| 段 | 说明 | 示例 |
|----|------|------|
| `ml` | 固定前缀（market line） | `ml` |
| `{market}` | 市场标识 | `cn`=A股, `us`=美股 |
| `{symbol}` | 标的纯数字代码 | `600519`, `000001`, `510300` |
| `history` | 固定关键字 | `history` |
| `{timeframe}` | 时间周期 | `1d`=日线, `1m`=分钟, `5m`=5分钟 |
| `{year}` | 年份 | `2024`, `2025` |

**表名示例：**
```
ml_cn_600519_history_1d_2024   -- 贵州茅台 2024年日线
ml_cn_000001_history_1d_2024   -- 平安银行 2024年日线
ml_cn_510300_history_1m_2024   -- 沪深300ETF 2024年分钟线
ml_cn_000300_history_1d_2024   -- 沪深300指数 2024年日线
```

### 4.3 日线数据采集（THS_HQ）

**iFinD 函数签名：**
```python
THS_HQ(thscode, jsonIndicator, jsonparam, begintime, endtime)
```

**参数说明：**

| 参数 | 示例 | 说明 |
|------|------|------|
| `thscode` | `'600519.SH,000001.SZ'` | 同花顺代码，逗号分隔 |
| `jsonIndicator` | `'open,high,low,close,volume,amount,changeRatio,turnoverRatio,pre_close'` | 指标名，逗号分隔 |
| `jsonparam` | `'Interval:D,CPS:1,fill:Omit'` | 日线、不复权、跳过无交易日 |
| `begintime` | `'2024-01-01'` | 开始日期 |
| `endtime` | `'2024-12-31'` | 结束日期 |

**CPS 复权参数：**

| 值 | 含义 | 使用场景 |
|----|------|---------|
| `1` | 不复权 | **数据存储（推荐）** |
| `2` | 前复权（分红再投） | 技术分析/展示 |
| `3` | 后复权（分红再投） | **策略回测（推荐）** |

**实测代码：**
```python
def fetch_daily(codes, start_date, end_date, cps=1):
    """
    获取日线行情
    
    Args:
        codes: str, 如 '600519.SH,000001.SZ'
        start_date: str, '2024-01-01'
        end_date: str, '2024-12-31'
        cps: int, 复权方式 1=不复权 2=前复权 3=后复权
    
    Returns:
        DataFrame: columns=[time, thscode, open, high, low, close, 
                   pre_close, volume, amount, changeRatio, turnoverRatio]
    """
    params = f'Interval:D,CPS:{cps},fill:Omit'
    result = THS_HQ(codes,
                    'open,high,low,close,pre_close,volume,amount,changeRatio,turnoverRatio',
                    params,
                    start_date, end_date)
    
    if result.errorcode != 0:
        raise Exception(f'THS_HQ 错误: {result.errmsg}')
    
    df = result.data
    # 添加复权因子字段（不复权时 factor=1）
    if cps == 1:
        df['factor'] = 1.0
    return df

# 实测结果（2026-08-10 ~ 2026-08-11, 600519.SH）:
# time       thscode    open    high   low   close   volume   amount  changeRatio  turnoverRatio  pre_close
# 2026-08-10 600519.SH  1343.0  1360  1336  1348.86  1258900  1.69e9  0.2734       0.1            1345.08
# 2026-08-11 600519.SH  1348.0  1353  1338  1346.50  1023400  1.38e9  -0.1750      0.08           1348.86
```

### 4.4 分钟数据采集（THS_HF）

**iFinD 函数签名：**
```python
THS_HF(thscode, jsonIndicator, jsonparam, begintime, endtime)
```

**参数说明：**

| 参数 | 示例 | 说明 |
|------|------|------|
| `thscode` | `'600519.SH'` | 同花顺代码，建议单只请求 |
| `jsonIndicator` | `'open,high,low,close,volume,amount'` | 指标名 |
| `jsonparam` | `'CPS:no,Fill:Previous,timeformat:LocalTime'` | 不复权，填充前值 |
| `begintime` | `'2026-08-11 09:30:00'` | 开始时间 |
| `endtime` | `'2026-08-11 15:00:00'` | 结束时间 |

**区间参数（可选，限定每日交易时段）：**

| 参数 | 示例 | 说明 |
|------|------|------|
| `Interval` | `1` | 1分钟(K线) |
| `Limitstart` | `09:30:00` | 每日起始时间 |
| `Limitend` | `15:00:00` | 每日截止时间 |

**实测代码：**
```python
def fetch_minute(code, date):
    """
    获取单只单日分钟数据
    
    Args:
        code: str, '600519.SH'
        date: str, '2026-08-11'
    
    Returns:
        DataFrame: columns=[time, thscode, open, high, low, close, volume, amount]
    """
    start = f'{date} 09:30:00'
    end = f'{date} 15:00:00'
    params = 'CPS:no,Fill:Previous,timeformat:LocalTime,Interval:1'
    
    result = THS_HF(code, 'open,high,low,close,volume,amount', params, start, end)
    
    if result.errorcode != 0:
        raise Exception(f'THS_HF 错误: {result.errmsg}')
    
    df = result.data
    # 时间列转为 Unix 时间戳
    df['time_unix'] = pd.to_datetime(df['time']).astype(int) // 10**9
    return df

# 实测结果（2026-08-11, 600519.SH）:
# 09:30  Open=1348.0  High=1352.65  Low=1338  Close=1346.50  Vol=...
# 共返回 31 条记录（30分钟数据量）
```

```python
def fetch_factors(codes, indicators_with_params):
    """
    获取因子数据
    
    Args:
        codes: str, '600519.SH,000001.SZ'
        indicators_with_params: list of (indicator, params)
            [('ths_market_value_stock', '2026-08-11,100'),
             ('ths_turnover_ratio_stock', '2026-08-11,100')]
    
    Returns:
        dict: {indicator: dataframe}
    """
    results = {}
    
    for indicator, params in indicators_with_params:
        result = THS_BD(codes, indicator, params)
        if result.errorcode == 0:
            df = result.data
            results[indicator] = df
        else:
            print(f'{indicator}: errorcode={result.errorcode}')
    
    return results

# 单指标调用示例
result = THS_BD('600519.SH', 'ths_market_value_stock', '2026-08-11,100')
```

```python
from concurrent.futures import ThreadPoolExecutor, as_completed
import time

def batch_fetch_minute(symbols, date, max_workers=10):
    """多线程批量获取分钟数据"""
    results = []
    
    with ThreadPoolExecutor(max_workers=max_workers) as executor:
        # 提交任务
        future_to_symbol = {
            executor.submit(fetch_minute, f'{s}.SH', date): s 
            for s in symbols[:100]  # 先处理100只
        }
        
        # 收集结果
        for future in as_completed(future_to_symbol):
            symbol = future_to_symbol[future]
            try:
                df = future.result()
                results.append(df)
                print(f'{symbol}: {len(df)} 条')
            except Exception as e:
                print(f'{symbol}: 失败 {e}')
            
            time.sleep(0.1)  # 避免 API 限流
    
    return pd.concat(results) if results else pd.DataFrame()
```

```python
        'trade_days': trade_days,
        'daily_records': daily_count,
        'missing_rate': f'{missing_rate:.1f}%',
        'status': 'OK' if missing_rate < 10 else 'WARN' if missing_rate < 50 else 'MISSING'
    }
```

#### RDS 在线扩容说明

```
RDS 存储扩容 — 阿里云控制台操作:
  路径: RDS控制台 → 实例列表 → 点击实例ID → 配置 → 变更配置
  操作: 修改磁盘大小，滑动滑块或输入数值
  影响: 无（在线扩缩容，业务不中断）
  生效: 通常 5~15 分钟后生效

推荐策略:
  第1步: 先买 100GB 起步
  第2步: RDS 监控页面看存储使用率，接近 70% 时扩容
  第3步: 每次扩容增加 50~100GB
  这样不会一次性买大容量导致浪费
```
